# Software Assessment 3

## The Games of Life

*A simple adaptation of Cellular Automata with customizable rules.*
***

> This project was made for the Australian NSW HSC Assessment 3 for Software Engineering.


This project primarily uses Pygame to run. External JSON files are needed for preset saves, etc.

To run the game, locate the `Main.py` file in the `GameFiles` directory.
